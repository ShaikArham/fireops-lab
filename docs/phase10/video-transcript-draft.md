# FireOps Lab video transcript draft

The 69-second silent review cut has English descriptive captions. It does not contain spoken audio. This proposed voiceover is for a later human recording and has not been presented as narration already in the MP4.

## Proposed narration

Payments leave records across systems. When a reference, amount or settlement date disagrees, an operations analyst needs clear evidence and a reliable next step.

FireOps Lab is an independent payment operations simulator built with fictional records.

CSV files are validated before import. A sample payment batch runs through a recorded lifecycle, but no money moves.

Reconciliation compares 1,250 payment instructions with 1,230 settlement records. Explainable rules surface exact and late matches, amount mismatches, duplicate candidates and unmatched rows.

An analyst can open a case, assign an owner, record evidence and retain status changes in an audit trail.

Monitoring rules show their thresholds, supporting evidence and possible benign explanations. An alert prompts human review; it does not prove fraud or money laundering.

Run-scoped insights explain the operational measures and export the same saved run to CSV.

This is a portfolio demonstration, not a live payment service, and it is not affiliated with Fire Financial Services. Explore the sample journey and source code in FireOps Lab.
